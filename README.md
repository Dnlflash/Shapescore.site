# Shapescore

Site que calcula seu potencial estetico e em seguida mostra pagina de pagamento para mais resultados como a gordura corporal usando o calculo da marinha americana

usa:
html,css,js e python com o flask

baixe os arquivos e execute o python, copie a url do terminal e abra no navegador
ou digite shapescore-site.vercel.app para usar, depois de inserir os dados clique em comprar e em seguida utilize a rota shapescore-site.vercel.app/resultado para continuar e ver os resultados

feito pra fins de estudo, manupulação de dom, reaquizições, desenvolvimento web em geral
atualmente migrando todo o calculo do js para o flask
